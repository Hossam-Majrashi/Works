## 📌 نبذة تعريفية

أطوّر حلولاً برمجية حقيقية تُستخدم يومياً في بيئة العمل: أنظمة إدارة بلاغات، أدوات معالجة بيانات ضخمة (+715 ألف سجل)، تطبيقات إنتاجية، وبناء رومات أندرويد كاملة من المصدر. أحوّل المشاكل التقنية إلى أدوات برمجية فعّالة.

موظف دعم فني ومساعد أنظمة في **شركة ركن المجرة التجارية (Almajarah)**، بخبرة عملية في تصميم وتوثيق البنية التحتية للشبكات، ترحيل ومعالجة قواعد البيانات لأنظمة الـ ERP (Retail Pro و Odoo)، ومتابعة أعمال الصيانة والعتاد وحلول الأتمتة.

### 📊 إحصائيات سريعة
- 🚀 **+12** مشروعاً برمجياً منشوراً
- 📈 **+715,463** سجل بيانات تم تنقيته وترحيله بنجاح بدقة 100%
- 🤖 **5** رومات أندرويد مخصصة مبنية بالكامل من المصدر (AOSP)
- 🌐 **48** لغة عالمية يدعمها الموقع مع التبديل الفوري ودعم كامل لـ RTL / LTR

### 🤖 رومات أندرويد مخصصة مبنية من المصدر (AOSP)

#### 📱 Xiaomi Mi 10T Pro (Apollo)
- **Evolution X — Android 14**: بناء AOSP كامل من المصدر مع طبقة Evolution X، ضبط نواة مخصص، إعداد Device Tree وإصلاحات HAL والكاميرا.
- **Infinity X — Android 16**: بناء AOSP أندرويد 16 من المصدر بمميزات Infinity X، ضبط Kernel و Device Tree وإدارة Vendor Blobs.

#### 📱 Motorola Moto G54 5G (Cancunf)
- **PixelOS — Android 16**: بناء PixelOS من المصدر مع ترجمة النواة وضبط شجرة الجهاز و Vendor Blobs — تجربة Pixel نظيفة على عتاد موتورولا.
- **Infinity X Vanilla — Android 16**: نسخة AOSP نقية وخفيفة بدون خدمات جوجل (بدون GApps) على نفس الجهاز.
- **LineageOS 23.2**: بناء ودعم روم LineageOS الرسمي لجهاز Moto G54 5G — نظام مفتوح المصدر مستقر وخفيف مع تحديثات أمان دورية.
